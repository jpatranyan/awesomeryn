## What do I need to get started

One thing that you must need to get started is a project. And depending on the
module use want to make use.

## What do I need to Work Order

First you need to make sure that you have project already defined. Second
is Work Type is already available and lastly is the Service associated with
the Work Types.

## What do I need to create Services and Work Type

Go to the settings page > core setup > work order. Defined all Service
you're offering, then create a Work Type and start associated services to the
Work Type.

## What do I need create Inspection

First you need to make sure that you have project already defined. Ensure you
defined the necessary setup for inspection. Categories, Areas, Items and Types.

## What do I need to create Inspection Categories

Go to the settings page > core setup > inspection > categories. Defined all Inspection
categories you'd like. E.g. Quality Assurance.

## What do I need to create Inspection Area

Go to the settings page > core setup > inspection > areas. Name all Inspection
areas you'd like. E.g. Lobby, Restroom etc.

## What do I need to create Inspection Item

Go to the settings page > core setup > inspection > items. Name all Inspection
areas you'd like. E.g. Table top, Chairs etc.

## What is Inspection or Training Inspection Type

This is the service you want to associate when every the system auto generated
a work order coming in from the inspection or training. E.g. "Needs Action"
