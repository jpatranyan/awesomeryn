# Ranyan — first 15 minutes

Copy this and tick as you go.

- [ ] Log in at https://{yourgivensubdomain}.ranyan.com
- [ ] Change you default password at your profile.
- [ ] Go to the setting page and upload your company logo.
- [ ] Under settings > role. Define a custom role name and assign modules
      that are accessible for the given role.
- [ ] Under settings > user. Create users and assign to role which best
      describe the user function.
- [ ] Create you first project.

Stuck on any line? Ask `/ryn` and name the step.
