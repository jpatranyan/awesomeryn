# Glossary

Terms that mean something specific inside Ranyan. If a word here also has a
generic meaning, the Ranyan meaning wins.

<!-- FILL -->

**Region** - Location where your company is operating.

**Branch** - A subset of region. A small part of the region where you want to
create a group.

**Client** - That groups the project. Client should belongs to a branch by option.

**Project** - The Job Site where all of the jobs are done. Optionally, project
can belongs to a client, branch and region.

**Inspection** - A routine task done by a Project/Job Site supervisor to ensure
every work is done the right way and or if there are places to be rework to
ensure client satisfaction.
**Categories** - A categorization of each inspection.
**Areas** - An area or an object to be inspected.
**Items** - This are the particular item to be inspected to an area or an object.
**Types** - A template or a blue print of a inspection that contains the Areas
and each Items to be inspected.

**Work Order** - These are the work requested in the job sites.
**Work Type** - These are the kind of work that need to done. E.g. Janitorial
**Services** - These are the actual work performed. E.g. Vacuum, Sweeping,
Restroom Clean etc.

**Training** - A module designed for managers or supervisor conducting a training.

**Supervisor Report** - A checklist that a supervisor needs to verify if it's
done and never forget on a daily based.
